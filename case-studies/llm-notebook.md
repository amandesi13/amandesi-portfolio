# Llama Notebook Exploration

Kaggle: https://www.kaggle.com/code/dhanjal13/llm-final

## Why It Matters

This notebook represents my hands-on exploration of modern LLM workflows, adapted from Meta's Llama material. The goal was not only to run a model, but to understand how LLMs behave as software components: prompts, inference flow, limitations, and where they can support real products.

## What I Learned

- Practical model setup and notebook workflow.
- Prompting and inference behavior.
- How LLM tooling can support document assistants, developer tools, and translation workflows.
- Why evaluation and product boundaries matter when using AI in real systems.

## Product Connection

This work connects directly to:

- Auslander Doc Assistant: document explanation and action extraction.
- Technical PDF Translator for Students: translation and review workflows.
- Future developer tools: LLM-assisted debugging, validation, and documentation.
